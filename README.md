# 宝可梦 宝石 · 极光大陆 (Pokémon Gems: Aurora)

一款致敬《宝可梦 朱/紫》与《宝可梦传说：阿尔宙斯》的 **3D 开放世界精灵收集冒险** 网页游戏。
纯前端实现（Three.js），无需安装，浏览器即点即玩。

**🎮 在线游玩：https://frankilito.github.io/pokemon-gems-aurora/**

## ✨ 特性总览

### 🌍 开放世界·极光大陆
- 一整块可无缝探索的大陆：**晨风草原 / 翠影森林 / 镜湖水乡 / 沙鸣海滩 / 霜峰雪山 / 熔心火山 / 回声洞窟 / 星陨遗迹 / 极光神殿**
- 动态昼夜循环（星空/日月/晨昏光照）、天气系统（晴/多云/雨/雷暴 + 雪山局部降雪）
- 摇曳草地、水面波光、熔岩池、体积感云层、远景山脉
- **高清角色**：主角与关键 NPC 采用 VRoid **VRM 动漫模型**（发丝弹簧骨物理+眨眼表情+11 状态程序化骨骼驱动），村民采用 ReadyPlayerMe 写实化身 + Mixamo 骨骼动画
- **贴图化世界**：地形草/岩/雪/沙四通道细节贴图+法线（ambientCG CC0），瓦顶木柱民居、夜晚窗户暖光、纹理草簇
- **奔跑 / 冲刺 / 跳跃 / 滑翔伞 / 攀爬 / 游泳 / 骑乘**（风速犬陆行 + 拉普拉斯渡水）

### 🐾 真实图鉴·151 只关都宝可梦
- 全部 151 只初代宝可梦 **3D 模型**（社区资源，多数带骨骼；无动画者由程序化步态系统驱动：跳跃/小跑/沉步/蛇行/悬浮/游动）
- **属性、种族值、招式、进化链、经验组全部采用 PokeAPI 官方图鉴数据**
- 昼夜出没差异、天气加成、群落行为、性格 AI（凶暴追击/胆小逃跑）
- **✨闪光个体**（1/96）与专属闪光模型/音效提示
- 真实宝可梦叫声（151 只 .ogg）

### ⚔️ 战斗系统
- 原地遭遇制回合战斗（阿尔宙斯式，无场景切换）
- 官方伤害公式：**18 属性克制 × STAB × 暴击 × 天气 × 能力等级**
- 命中/闪避、优先度、状态异常（麻痹/烧伤/中毒/冰冻/睡眠/混乱）、吸血/反伤/多段/畏缩
- 升级学招（4 招置换）、**等级/进化石/连接绳进化** + 野外进化仪式演出
- 道馆馆主 & 路人训练家挑战、传说宝可梦驻守（急冻鸟/火焰鸟/雷雨夜的闪电鸟/深渊超梦）

### 🎯 捕捉系统（阿尔宙斯式即时捕捉）
- 肩视角瞄准 + 抛物线投球 + 目标锁定
- 官方捕获率公式（球种加成 × 状态加成 × HP 削弱）
- **潜行背刺加成**、树果引诱、战斗内捕捉
- 吸入 → 三次摇晃 → 星爆的完整仪式感

### 📖 完整游戏循环
- 御三家选择 → 捕捉教学 → **三道馆挑战**（岩/水/火）→ 星陨遗迹解谜 → **极光神殿终章**（超梦事件战）
- 支线任务（皮卡丘女孩/渔夫的鲤鱼王/夜捕幽灵系/捕捉大师）
- 商店购物、宝可梦中心治疗、图鉴收集（发现/捕获两级）、个体值/性格培养
- 掌机 RPG 风 UI：队伍/背包/图鉴/大地图/任务/系统 六页签，小地图+任务标记
- **localStorage 自动存档** + 导出/导入

### 🌐 联机（PeerJS）
- 5 位房间码连接好友
- **精灵交换**（双确认制）
- **好友对战**（主机权威回合制同步）

### 🎵 音频
- WebAudio 程序化 BGM（野外昼/夜/战斗/胜利/进化五主题）+ 全套合成音效

## 🕹️ 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动（Alt 慢走潜行） |
| Shift | 冲刺（消耗体力） |
| 空格 | 跳跃 / 空中展开滑翔伞 / 墙面跳离 |
| 鼠标右键(按住) | 瞄准 |
| 鼠标左键 | 投掷精灵球（瞄准时） |
| B(按住)+左键 | 投掷树果 |
| R | 切换精灵球种类 |
| F | 对最近的野生宝可梦发起战斗 |
| E | 与 NPC 交谈 / 调查 |
| G | 召唤/收回坐骑 |
| M / Esc | 总菜单 |
| 滚轮 | 相机距离 |

> 陡坡前推即攀爬；深水自动游泳（注意体力）；骑乘状态入水自动换乘拉普拉斯（需碧波铃铛）。

## 🚀 本地运行

```bash
# 任意静态服务器即可
python3 -m http.server 8944
# 或双击 启动.command (macOS)
```

## 🛠️ 技术

- **Three.js r170+**（ESM，无构建步骤）
- 解析式高度场地形 + 顶点色群系渲染，实例化植被
- GLB 模型（Draco + WebP）按需加载缓存；动画名模糊匹配 + 程序化步态兜底
- PokeAPI 数据离线烘焙（`tools/fetch_data.py`）；模型批量抓取（`tools/fetch_models.py`）

## 🧪 测试与调试

```bash
# 先启动本地服务(8944), 再执行:
node tools/shoot.mjs test        # 游戏内57项单元+集成测试(?autotest): 克制表/伤害公式/经验曲线/
                                 # 能力值/升级进化/捕获率/存档往返/图鉴数据完整性/生成表/无头战斗模拟
node tools/e2e_battle.mjs        # E2E: 真实DOM驱动一场完整野战(遭遇→选招→击倒→经验→回世界)
node tools/e2e_capture.mjs       # E2E: 指针锁定→瞄准→投球→摇晃判定→入队/图鉴/存档
node tools/e2e_save.mjs          # E2E: 存档→刷新页面→位置/队伍/背包/图鉴/时间恢复
node tools/shoot.mjs shot out.png [query] [waitMs]   # 定点截图 / eval / drive 见文件头
```

- 游戏内按 **F3**（或 URL 加 `?debug`）开启性能面板：FPS/帧耗时/drawcall/三角形/地形块/草实例/精灵AI状态/JS堆
- `?dev` 跳过标题直接进入测试局；`?autotest` 跑测试并显示结果浮层
- 测试也可直接在浏览器打开 `http://localhost:8944/?autotest` 查看

## ⚙️ 设置与无障碍

总菜单(M) → 系统：总音量/音乐/音效/精灵叫声分组音量、镜头灵敏度(30%~200%)、
减少镜头晃动（晕动症友好：震屏与FOV冲击大幅降低）、界面字体三档缩放。
设置独立于存档持久化（`localStorage: gem_settings`），导入导出存档不影响个人设置。
